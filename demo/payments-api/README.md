# payments-api (demo)

A miniature payments service kept here as **review material** for the DevDigest
agents. Nothing imports it — it sits outside every package's `tsconfig`, is never
built and never runs. The layout mirrors the demo PR the starter seeds
(`acme/payments-api` #482), so a review of this repo lands findings on the same
paths the fixtures talk about.

Treat it as sample input, not as a reference implementation.
